# 单机版产品与系统重构决策

日期：2026-11-06  
适用分支：`feat/exploration-progression-foundation-2026-11-05`

## 产品方向

保留《百炼英雄》的轻操作外壳（竖屏、摇杆移动、自动战斗、短反馈循环），但不复制其依赖服务端、付费加速和社交比较的商业化结构。单机版的长期深度由阵容策略、属性克制、羁绊、技能时机、装备构筑、地图探索、试炼和收集承接。

核心原则：先达到参考游戏的基础体验对标，再验证超越；创新不能代替主城、地图、队伍、战斗、探索、成长和性能的基线验收。

## 原版职能到单机替代

| 原版职能 | 单机版替代 |
|---|---|
| 摇杆移动、自动攻击 | 保留低门槛操作，增加可选技能策略覆盖层 |
| 挂机产出、养成、推图、卡关 | 保留短循环，卡关转为阵容调整、定向刷取和支线挑战 |
| 抽卡获取英雄 | 以任务、地图进度、碎片和确定性兑换为主 |
| 狗粮/觉醒长周期 | 定向区域产出、前置玩法质变、后期可选深度 |
| 装备随机 | 保留受控词条随机，提供流派目标和可理解的重铸成本 |
| 排行榜/公会 | 试炼、无尽、成就、图鉴和多周目 |
| 广告/IAP加速 | 不作为核心循环前提；未来若收费，优先完整内容解锁 |

## 战斗与阵容

- 保留移动即操作、自动攻击为默认体验。
- 战前展示敌方属性和威胁构成，让阵容选择有信息基础。
- 关键技能可配置自动释放、保留或条件释放；不得破坏默认自动战斗。
- 敌方设计应区分爆发、AOE、治疗/增益等威胁，并提供可读预警和针对解法。
- 五行克制 ±30% 仅作为平衡假设，需经模拟和实机验证，不能直接视为已确认参数。

## 养成经济

- 英雄获取应可规划；地图与任务奖励给出清晰目标。
- 种族材料可定向投放，但避免把重复刷取变成唯一推进方式。
- 觉醒前期应较早出现玩法质变，后期再提供可选深度。
- 装备词条提供Build差异，但重铸应有成本边界和保底/锁定策略。
- 主线有明确终点；无尽/试炼、全收集和多周目属于后续内容，不计作现有能力。

## 离线收益：安全边界

纯本地客户端无法证明系统墙钟未被修改，也无法阻止有能力的玩家编辑本地存档。随客户端分发的加密密钥不能构成绝对防篡改边界。产品不得承诺“本地彻底防作弊”。

当前策略：
1. 结算设置最短门槛、收益封顶和资源上限。
2. 区分缺失时间戳、非法时间戳、当前时间非法、时钟回拨、低于门槛和封顶结算。
3. 异常时不清档、不扣除已有资源；本次不发放离线收益。
4. 运行期间可用单调时钟检测墙钟跳变；重启后不能把上次进程的单调时钟值当作离线时长。
5. 远端时间广播只能是联网可选增强，不得成为纯离线核心玩法的依赖。
6. 备份、格式校验和版本迁移用于防损坏与兼容，不等于防止玩家修改存档。

## 工程现状与边界

- `RecruitmentManager` 已有任务解锁、碎片解锁和碎片保底，不另建平行招募系统。
- `HeroPowerCalculator` 已统一处理当前战力属性，不用简化公式替换现有计算；显示战力必须与实际战斗属性一致。
- `OfflineManager` 已有本地时间戳、最低结算门槛和封顶；2026-11-06 增加可观测的时间异常分类及回归测试，但仍不能防止玩家反复前拨系统时间或编辑存档。
- `SaveManager` 当前为单主存档 + 备份，schema version 1；多存档槽位尚未实现。
- 探索迷雾、探索度和地图面板已有首版；地图/传送闭环和真机视觉验收仍未完成。
- 无尽、试炼、每日挑战和多周目尚未形成完整模式。

## 优先级

### P0：离线收益可信性
完善异常时间分类、重复结算检查、封顶策略和正常时区/重启回归。保持已有进度安全，并明确纯本地防护边界。

### P1：策略型卡点与英雄解锁
复核现有任务/碎片/保底曲线；增加战前敌情预览、技能策略和可替代资源路线。以实测确认阵容选择能改变战斗结果。

### P2：养成经济与Build
定向材料、觉醒节点、装备词条和重铸成本用数据表及模拟测试验证。

### P2：长线内容
设计主线终点、试炼/无尽、图鉴成就和多周目；多存档先定义槽位、备份、迁移、删除与崩溃恢复。

### P3：商业化清理
移除没有广告服务支撑的免广告/广告翻倍占位；不实施支付或广告 SDK，除非另行确定产品范围。

## 验收门槛

- 设计假设与已验证事实分开记录。
- 数值改动需有模拟或回归测试。
- CI 通过只证明代码与逻辑验证，不代表玩法平衡、视觉品质或对标完成。
- 每个对标模块必须经过真实参考采样、同分辨率比较、差距修正和复测。
- 优先扩展现有管理器与数据源，避免重复状态、平行规则和第二套存档。
