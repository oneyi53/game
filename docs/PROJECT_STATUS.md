- 用户反馈当前地图逻辑仍不符合预期：地图必须铺满竖屏、镜头随角色移动，任务推进时区域与场景发生变化，UI 需要采用成熟竖屏 RPG 的叠层布局。

  - Camera2D 设为 1:1，并按队长投影位置跟随；边界与地图投影同步。
  - 摇杆屏幕方向重新映射到逻辑坐标；角色遮挡深度使用新投影的纵向顺序。

  - 新档在营地沿出口进入首个探索区；完成苔冠区域 Boss 主线任务后自动推进落叶幽谷，完成幽谷主线任务后自动推进朝露林地。
