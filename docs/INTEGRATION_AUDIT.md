## 主线新增的原创角色素材
- 从 `main` 发现根目录 `5.png` 和 `image.png` 两个 1024×1024 角色动作表。实际文件签名是 JPEG（不是 PNG），因此在 `assets/art-v1/source/` 中按真实格式保存为 JPG，不修改原始像素。
- `5.png` 的棋盘格背景、`image.png` 的白色背景都已烘焙进图片，不是真透明通道；暂作为原始来源素材保存，不能直接作为透明 SpriteFrames 导入。后续需背景清理、逐帧裁切、锚点与动作方向校验后再接入运行时。
- 这两张图不是当前运行时动画已完成的证据。
