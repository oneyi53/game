## 设计前提（用户定）

- 单机版，资源限制放宽：原版因需购买资源才显得不好的地方不用在意。
- 学习目的：更好理解对标游戏，开工时不走弯路；学习结论收敛为开工避坑清单。
- 核心循环：主城整备 → 大地图探索/战斗 → 收集资源 → 养成队伍 →
  打更强 BOSS、开新图 → 回主城整备。
- 操作：单摇杆移动，靠近自动打、靠近自动采，无自动寻路；
  “自动”倾向于靠近即自动，不是可开关托管按钮（未证实部分不进第一版）。
- 工程铁律：数值全部落表，运行时只做“基础值 + 带 id 的修正项”；
  转生与离线先写保留/重置清单与追算账本，再写功能；
  离线收益：用户定为无所谓，M0 用简化公式 + 8/12 小时上限即可，
  “在线离线统一模拟器”不作为 M0 门禁，后续再定；
  节奏用里程碑与选择来卡，不用付费墙来卡；
  本地存档自动保存兜底、可备份、可迁移。
