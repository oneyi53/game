# 原创美术生成记录（历史说明）

> 本文保留最初美术风格、图集内容与生成约束的历史记录。若与当前资源目录/接入状态冲突，以 `README.md`、`ART_ASSET_CATALOG.md` 和 GitHub main 为准。

## 已确认的原创风格

光滑扁平卡通、大头小身、粗描边、高饱和、脚底影、菱形地砖；英雄、怪物和装备均为 Hero World 自有角色与设计，不借用其他游戏的具体人物、怪物、装备造型和名称。

## 原始图集

- `heroes-v1.png`：6 名英雄。
- `monsters-v1.png`：10 类普通怪物。
- `bosses-v1.png`：2 个 Boss。
- `scene-v1.png`：场景参考图，不作为整张地图背景。
- `equipment-v1.png`：6 件基础散件。

## 当前资源归档状态

- 五张原始分类图集保存在 `assets/art-v1/`。
- 单体英雄、怪物、Boss、装备与场景 PNG 已切分并保存在 `sprites/`；规格见 `SPRITE_SPEC.md`。
- 三套装备共 18 张独立部件 PNG 已归档于 `sprites/equipment_sets/`。
- 用户确认的原创技能特效图集位于 `effects/effect_atlas.png`。
- Godot 应用图标位于 `branding/icon.png`。
- 预览图位于 `sprites/previews/`，仅用于人工核对。

## 当前仍需完成的表现工作

- 英雄、普通怪物和 Boss 的行走、攻击、受击、死亡动画。
- 装备外观叠加到角色战斗立绘。
- 四个区域各自独立的地标、植被和配色主题。
- Godot 4.7.2 中的导入、启动、战斗特效与移动端画面验收。

## 使用约束

- 优先复用现有原创素材，不重复生成同类资源。
- 不把整张场景参考图当背景；地面、碰撞、遮挡仍由游戏场景系统控制。
- 图集颜色框、背景和 Boss 提示圈不是品质或战斗逻辑。
- 本文原始制作说明曾包含 Godot 4.3、未切图和未接入等旧状态，现均视为历史记录，不再作为当前执行指令。
