# Hero World 美工成套可直接用清单 v1

风格已由用户确认：光滑扁平卡通、大头小身、粗描边、高饱和、脚底影、菱形地砖、武器与体型一眼分工。
以下 5 张都在 ~/workspace/art-sample/usable/，1920×1280 PNG，可直接给后续工作用。
只改显示和布局，不动数值、逻辑、任务、门禁、存档结构。

## 直接用上的方法（按顺序）
1. 装备最先可用：equipment-v1.png 按 3×2 切成 6 张单图标，背包和装备面板直接用单图标；框色按游戏品质系统重画，不要把图里灰绿蓝紫金红的顺序当成品质等级。
2. 英雄、小怪、Boss：按上面给的位置切成单体，抠掉背景、留脚底影，缩放到游戏内体型档（英雄和小怪同档，Boss 约 2 倍），再贴到现有等距投影层上；血条、红圈仍由代码画，不要把图里的红圈当成固定贴图。
3. 场景：不要把整张 scene-v1.png 当背景贴上（会挡地图和走位）。只切地标单体：塔、雕像喷泉、圆冠树、营火、宝箱，按固定坐标摆进地图；地面仍用现有菱形地砖画法。
4. 每步在 Godot 4.3 副本验证零报错，再出竖屏实拍：英雄一排、小怪一排、Boss 一局、场景全景、装备面板各一张。

## 不要做的事
- 不要改任何数值、任务目标、奖励、门禁、掉率。
- 不要把图里的框色、红圈、背景当成数值或逻辑。
- 不要用 KayKit 低模 3D 和 game-icons 单色图标那套已否决的方向；本套为准。
- 单体切图时不要改人物和怪物的武器、体型、配色，只做抠图和缩放。
